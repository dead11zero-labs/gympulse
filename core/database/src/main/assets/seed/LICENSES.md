# Lizenzen der Seed-Daten

- **Übungen** (`exercises_v1.json`: Namen (en), Anleitungen, Muskelgruppen, Bild-Links) stammen aus
  [free-exercise-db](https://github.com/yuhonas/free-exercise-db) und stehen unter der Unlicense (Public Domain).
- **Deutsche Namen** und **Gerätevorlagen** (`equipment_templates_v1.json`) sind eigene Inhalte von GymPulse
  und stehen unter CC0-1.0.
- **Kraftgeräte** (47 Geräte aus `tools/seed/data/kraftgeraete_datenbank.csv`, davon 18 als eigene Einträge mit
  `source: gympulse` in `exercises_v1.json`: Namen DE/EN, Gerätetyp, Muskelgruppen) sind eigene Inhalte von
  Jörg bzw. GymPulse und stehen unter CC0-1.0.
